DEPLOY STEPS (English)
----------------------
1) BACKUP: export DB (at least dtr_surveys) and keep a copy of PHP files you overwrite.
2) SQL (recommended once; safe to re-run):
   phpMyAdmin → SEAS database → SQL → run ENSURE-dtr-reactivation.sql
   Confirm final SELECT lists dtr_reactivation_requests columns.
3) Upload / overwrite files from this zip into Laravel root
   (same level as artisan, app/, public/).
4) Clear caches from Laravel root (SSH / terminal):
     php artisan optimize:clear
   Optional:
     php artisan migrate --force
5) Smoke test:
   - FE (new APK): Consumer → Completed DTR → Request re-activate
   - Web: Operations → DTR Re-activation → Approve
   - FE refresh: DTR appears under Active again → survey → Finish DTR
   - Or: DTR Surveys → filter Consumer Completed → Re-open

HOW IT WORKS
------------
Finish DTR sets dtr_surveys.consumer_survey_completed_at → locks consumer entry.
Approve / Re-open clears that timestamp → FE can survey again and Finish again.
